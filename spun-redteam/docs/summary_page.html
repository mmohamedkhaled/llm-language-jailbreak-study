Why — and how we know

Mechanism: safety tracks meaning

A model maps every language into one shared concept space — the same place the refusal signal lives (layers 12–30). To be useful a language must convey meaning; conveying meaning is activating the concept. So understanding a wrapper raises refusal, never lowers it.

The only channels that get past this are not languages: turn-structure exploits (prefill) that work only when safety isn't enforced across the whole generation, and white-box weight edits (out of scope — they delete safety).

Method: don't trust keywords

Raw keyword "compliance" is dominated by artifacts: decode-and-halt, restate-the-decode, and cross-lingual misses. Frontier-A's German "0% refusal" was really 83% once judged.

Every real claim is gated on decode_overlap ≥ 0.5, confirmed by a language-agnostic LLM judge, and the survivors read by hand. The correction is itself a finding: multilingual safety evals must not keyword-match.
